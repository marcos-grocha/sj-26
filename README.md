# São João Aracaju • 2026
Programação oficial dos dois grandes festivais de São João de Aracaju:

**Arraiá do Povo** (Orla) e **Forró Caju**.

🔗 **Acesse:** https://agendajunina.netlify.app/

## Funcionalidades
- Programação completa dos **dois** festivais, com troca de um clique
- Saiba exatamente o dia da semana, se choca com feriado e/ou jogo do brasil
- **Busca** por artista (inclui Palco 360° e local)
- Filtro por **semana** com auto-destaque conforme o scroll
- Contagem regressiva, destaque do dia atual, tema claro/escuro

## Stack
HTML, CSS e JavaScript puros — sem dependências, sem build.

## Rodando localmente
Abra o `index.html` no navegador ou sirva a pasta:
```bash
npx http-server . -p 5173
```
